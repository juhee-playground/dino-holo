# 🦖 DINO HOLO

A CSS-powered Dinosaur Trading Card Experience.

An interactive dinosaur encyclopedia inspired by holographic trading cards.

## ✨ Features

- Holographic Dinosaur Cards
- 3D Card Interaction
- Rarity-based CSS Effects
- Interactive Dinosaur Museum
- Dinosaur Encyclopedia
- CSS Card Lab

## 🛠 Tech Stack

- React
- TypeScript
- Vite
- SCSS
- CSS Custom Properties
- Pointer Events

## 📱 Responsive

Optimized for desktop and mobile devices.
